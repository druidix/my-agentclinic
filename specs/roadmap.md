# Roadmap

Very small phases, each leaving the app runnable.

1. **Server skeleton:** install Express, serve "Hello AgentClinic" from `src/index.ts`, add a `start` script.
2. **Layout:** shared EJS layout, stylesheet, and navigation.
3. **Dashboard shell:** a staff dashboard page with placeholder panels.
4. **Agents:** list agents (in-memory seed data).
5. **Ailments:** list ailments and show which agents have them.
6. **Therapies:** list therapies and link them to ailments.
7. **Appointments, view:** list scheduled appointments on the dashboard.
8. **Appointments, booking:** a form for an agent to book a therapy.
9. **Persistence:** move the data to SQLite.
10. **Polish:** responsive design, accessibility, and marketing-quality visuals.
